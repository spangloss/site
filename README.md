# spangloss.ai

Source for [spangloss.ai](https://spangloss.ai), the site for [spangloss](https://github.com/spangloss/spangloss): security labels for AI agent telemetry.

A static Astro site: a landing page and a Notebook of longer write-ups, with an RSS feed, a sitemap and generated Open Graph images.

```
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
```

See [CLAUDE.md](CLAUDE.md) for how the site is organized and how to add a Notebook entry.
